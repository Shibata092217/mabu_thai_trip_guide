GitHub Pagesの公開手順

このページでは、GitHub Pages で自分のサイトを公開する手順を 1 から順番に説明します。

← しおりページに戻る
1

GitHub にログインする

GitHub のサイトにログインし、右上の「+」から「New repository」を選びます。

2

リポジトリ名を決める

名前は「yourname.github.io」のようにすると、個人サイトとして使いやすいです。

3

HTML ファイルをアップロードする

作成したリポジトリに、index.html と style.css をアップロードします。

4

Settings から Pages を開く

リポジトリの「Settings」タブを開き、「Pages」を選びます。

5

Source を「Deploy from a branch」にする

「Source」で「Deploy from a branch」を選び、branch を main、folder を /root にします。

6

公開完了を待つ

しばらくすると「Your site is live at ...」と表示されます。URL をコピーします。

7

公開URLを開く

表示された URL をブラウザで開くと、サイトが見られます。

8

内容を変更したいとき

index.html を編集してコミットすると、すぐに反映されます。
